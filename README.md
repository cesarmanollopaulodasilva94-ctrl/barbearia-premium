# Elite Barber Club

Site institucional premium para barbearia, desenvolvido com React, TypeScript, Tailwind CSS e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Configuração obrigatória

Antes da publicação, atualize as informações demonstrativas em `src/App.tsx`:

- `WHATSAPP_NUMBER`: número no formato internacional, somente números;
- nome da barbearia e identidade visual;
- endereço, telefone, Instagram e horários;
- preços e descrições dos serviços;
- depoimentos e números institucionais;
- URL do mapa no iframe.

As imagens são carregadas de fontes externas do Unsplash e podem ser substituídas por fotos próprias da barbearia.
